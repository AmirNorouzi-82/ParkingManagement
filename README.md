با سلام و عرض ادب خدمت استاد گرامی .

موضوع پروژه پایانی گروه ما در مورد مدیریت پارکینگ است و ثبت می کند کدام ماشین در کدام جایگاه از پارکینگ برود و مدیریت می کند که کدام جایگاه از جایگاه های پارکینگ خالی یا پر است . 

لازم به ذکر است که پوشه اصلی پروژه ما ، پوشه src است .

این پروژه ، پروژه پایانی گروه ما است و با پروژه ای که در طول ترم گروه ما انجام داد و فعالیت کلاسی گروه ما محسوب می شود ، متفاوت است .

لیست وظایف اعضای گروه به شرح زیر است : 
نفر اول دانشجو امیرحسین نوروزی امامچائی: 
1- پیاده سازی Domain Class ها 
2- پیاده سازی DbContext

3-ایجاد Migration

4-ساختاربندی و پوشه بندی پروژه بر اساس معماری کلین (Clean Architecture )  
5-پیاده سازی Interface ها 
6-پیاده سازی Repository ها 
7-پیاده سازی Controller ها 

نفر دوم دانشجو علیرضا ایزدی محصل زهانی :
1-تکمیل معماری کلین (Clean Architecture)
2-پیاده سازی DTO ها 
3- پیاده سازی Entity Configuration ها 
4- پیاده سازی Mapping ها با استفاده از MediateR

5- پیاده سازی Feature ها ( CQRS) 
6- اضافه کردن unit of work به Repository ها 

نفر سوم دانشجو مهدی هاشمی :
1- پیاده سازی مدیریت خطا در Middleware 

2- پیاده سازی ثبت و مدیریت لاگ با استفاده از کتابخانه Serilog

3- پیاده سازی امنیت و احراز هویت با  JWT
